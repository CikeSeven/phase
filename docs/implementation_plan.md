## 3. E1：远程 MCP

设计入口：[扩展设计 §2–§3](./agent_extensions_design.md#extensions-mcp)。

- [x] 为动态工具增加稳定来源 ID、原名映射、定义修订和效果分类；保留既有 Tool/ToolExecutor 入口。
- [x] 增加 MCP 配置仓储与安全凭据引用，运行固定工具目录和连接配置；禁用立即阻止后续派发。
- [x] 实现显式 Streamable HTTP、初始化协商、JSON/SSE 响应、分页工具列表、会话关闭和请求取消。
- [x] 加入服务列表/编辑/连接检查/工具列表，以及助手范围设置；检查连接不调用业务工具。
- [x] 将文本、结构化结果和图片映射到现有回填与产物链路；大结果有界处理。
- [x] 连接失败、响应丢失、工具定义变化和超时成为可见错误，不自动重发已派发工具。

交付用例：本地可控 HTTP MCP 服务提供“读取样本文档”工具，四协议真实适配器发出调用，确认后返回并保存结果，再生成最终回答。覆盖停止时的等待响应/空闲 SSE、鉴权失效、工具目录变化与禁用；不以静态工具定义或连接成功当作闭环完成。

实现入口：[MCP 功能](../lib/features/mcp/)、[配置仓储](../lib/data/repositories/mcp_server_repository.dart)、[来源与快照](../lib/data/models/tool_source.dart)、[测试](../test/features/mcp/)。本机可控 HTTP 服务的交付用例已通过；设备与外部服务的实际验收范围见下面记录。

依赖选择：已核对 [mcp_dart 2.4.2](https://pub.dev/packages/mcp_dart/versions/2.4.2)（2026-09-03 发布、MIT、Dart ^3.4.0），具有 Streamable HTTP、AbortSignal/关闭、图片/结构化内容支持及相应测试，依赖 http/crypto/meta。本批保留已验证的 Dio 客户端；替换 SDK 时需重新验证鉴权、会话恢复、取消与“不重发已派发工具”契约。`crypto 3.0.7` 已从间接依赖改为直接依赖，用于名称/定义 SHA-256 摘要，未升级版本。

2026-09-19 E1 实现与验收记录：

- 支持 MCP `2025-06-18`、`2025-03-26`，JSON/SSE、分页、`tools/list_changed`、协议取消及 DELETE 关闭；不自动重试业务调用。每次派发前重新核对目录，确认前后和真正发送前核对权限。
- 无凭据/Bearer 与自定义请求头可配置；自定义头值全部进入安全存储，配置/快照只保存引用。更换凭据创建新引用，旧运行保持原引用；删除失败保留禁用条目供重试。地址禁止 userinfo、查询参数及片段；不跟随 HTTP 重定向。
- 响应/目录总量上限 8 MiB，目录最多 100 页/1000 个工具；模型文本预览最多 6 KiB，超限保存完整文本产物并给出引用。PNG/JPEG/WebP 复用图片回填；关闭图片能力不解码或保存图片；资源链接不自动下载。服务端只读提示不授予权限。
- 已执行格式检查、`flutter analyze --no-pub`、`flutter test --no-pub` 和 `git diff --check`；完整 Flutter 测试 810 项通过、4 项预览跳过。MCP 55 项测试包含真实 HTTP/SSE、四协议文本/结构化/图片回填、确认/撤权、定义变化、超时、等待响应/空闲 SSE 停止及最终落库。通知测试服务显式关闭 HTTP 输出缓冲，避免把尚未发送的事件误判成客户端失败。
- 工具链恢复网络/监听权限后，重新解析相同锁定依赖以消除先前可写 SDK 副本造成的分析器路径冲突，并重新生成代码。未升级依赖。SDK 候选归档、探针与测试日志均在忽略的 `build/`。
- 用户明确允许一次无损覆盖升级：schema 3 → 4 仅新增 `mcp_servers` 和工具来源可空列；假数据/假密钥测试验证会话、助手、运行、工具结果和外键保持，重开不会重复建表。例外同步记入 AGENTS 第 5 节，不扩大其他开发期兼容范围。
- Profile 构建通过（APK 约 140.2 MB），已在授权设备 `1b8418ca`（2211133C、Android 16/API 36）使用 `adb install -r` 覆盖安装，启动 `Status: ok`、冷启动 1304 ms。UI 层可访问新增 MCP 配置表单，原有助手页面正常读取。安装前加密数据库备份保存在忽略的 `build/e1_device_database_before.tar`，未卸载、清数据或更换签名。
- 装机与基础页面可访问不代表完整真机验收；外部 MCP/模型网关、Android 生命周期、预测返回和 Profile 帧性能尚未验证，未修改原生桥接。

## 5. E3：Linux 工作区与命令

设计入口：[环境 §5](./agent_extensions_design.md#extensions-runtime)、[进程 §6](./agent_extensions_design.md#extensions-process)。分三次可验证交付，不一次铺满终端 UI。

### E3.1 运行可行性与安装

- [ ] 固定首批 Ubuntu 24.04 ARM64 镜像清单、ABI、发布摘要和下载大小；明确 PRoot/loader 来源、构建方式、许可与版本。
- [ ] 在 JNI 库目录打包执行文件，验证当前 targetSdk 上启动；不降低 SDK 或更换应用 ID。
- [ ] 实现下载、校验、staging 解压、安装检查、取消、空间不足和失败清理。
- [ ] 增加环境状态与工作区仓储，环境/依赖与用户文件分目录；重置/卸载影响明确且不自动删除工作区。

完成条件：授权设备上从未安装环境到 shell ready 可复现，固定命令退出码和文件结果正确；取消安装后原有环境/工作区仍可用。记录 APK 增量、下载量、安装及峰值空间，不能复用 Aether 的 Alpine 数字。

### E3.2 进程桥与命令工具

- [ ] Pigeon 增加原始进程 API：启动、字节事件、stdin、关闭、取消及一次退出事件；按 owner/processId 归属。
- [ ] 同时消费 stdout/stderr，处理 UTF-8 边界、背压、尾部输出和上限；输出产物与应用状态写入分开处理。
- [ ] 实现 shell 工具、固定运行环境/工作区、确认参数、默认超时与结果保存；独立非交互进程不继承上次 cd/变量。
- [ ] 整理执行宿主的命令任务类型、前后台和通知停止归属；不依赖聊天 Activity 常驻。
- [ ] 取消传到底层进程组，回收子进程/FD；重启按中断失败保存，不重跑命令。

完成条件：固定脚本分别覆盖成功、非零退出、等待 stdin、无输出、持续大输出、子进程和停止；结果经真实模型适配器回填。真机验证后台/Activity 重建/服务停止，测试产物放 build/。

### E3.3 工作区体验

- [ ] 会话绑定/切换工作区，附件导入副本与产物导出，使用中的工作区删除处理。
- [ ] 环境安装界面展示真实阶段、依赖和大小；准备失败返回明确入口。
- [ ] 基础管道稳定后再加入 PTY 终端、尺寸变化、Ctrl-C、会话退出和页面状态恢复；PTY 可在 E4 之后交付，不阻塞 stdio。

完成条件：会话任务生成文件后可在工作区和产物查看；切换会话不改变运行绑定，关闭终端页面不会错误终止别的任务。普通聊天不启动 Linux。

## 6. E4：本地 MCP 与依赖

设计入口：[扩展设计 §3.4](./agent_extensions_design.md#extensions-mcp)。

- [ ] 添加 Node/npm、Python/uv、Git/搜索工具的按需安装，记录版本和结果，安装失败/取消保留已知状态。
- [ ] MCP 配置开放 stdio，选择已有环境/工作区及 executable/argv/cwd；敏感环境变量仅保存引用，npx/uvx 依赖预先安装并固定版本。
- [ ] Dart 客户端直接连接进程原始管道，stderr 与 JSON stdout 分离，stdin 可持续写入。
- [ ] 绑定服务会话与进程生命周期，关闭/取消/服务异常不会遗留进程或自动重跑调用。
- [ ] 会话工具目录变化沿用 E1 的定义修订与权限规则，清理空闲后台连接。

交付用例：固定版本 Node 和 Python 各一个 MCP 服务，完成发现、确认调用、分片输出、错误、停止及退出；再选择一个实际 npm/uvx 服务做明确环境下的兼容性检查。依赖安装不是普通 tools/call 的隐藏步骤，PTY 不能替代 stdio。

## 7. E5：Agent 上下文与计划

设计入口：[扩展设计 §8](./agent_extensions_design.md#extensions-planning)。

- [ ] **预算先行**：提取 ContextBuilder，计算工具定义/系统提示/消息预算，预留输出并保留完整工具组；超限有明确结果。
- [ ] **分支摘要**：保存覆盖范围和来源，切分支后失效；摘要请求可停止，用量独立，失败不删除历史或无限重试。
- [ ] **Plan Mode**：只开放宿主确认的只读工具，版本化计划卡、编辑/批准/取消；批准后创建关联执行运行，具体动作继续确认。
- [ ] **记忆**：助手/全局范围、来源、编辑/删除和关键字检索；显式写入默认 ask，不从工具结果自动提炼长期事实。

交付用例：长会话在预算内保持任务约束和工具结果；计划阶段拒绝通用 shell/未知效果 MCP；修改计划后旧批准失效；记忆可查、改、删且不会被摘要重新写回。四项可分批，不等记忆完成才交付预算管理。

## 8. E6：系统命令通道

设计入口：[扩展设计 §7](./agent_extensions_design.md#extensions-channels)。

- [ ] Shizuku 安装/运行/授权引导 → UserService 单次命令 → 管道输出与退出码 → 撤权/断连/停止。

- [ ] 运行配置显示并固定通道；原生与 Dart 保留同一调用归属，失败不换身份/环境重试。

每条通道单独验收并交付。Termux 双向服务桥只有具体本地服务器需求时再做；E4 的 stdio 不等待 Termux。Root 不混入本批。

## 10. E8：单子代理

设计入口：[扩展设计 §10](./agent_extensions_design.md#extensions-subagent)。

- [ ] 定义子代理配置与 parentRunId/agentId，复用同一 AgentLoop、Provider 和 ToolExecutor。

## 11. 可单独排期的产品扩展

设计入口：[扩展设计 §11](./agent_extensions_design.md#extensions-product)。下列任务不因扩展主线完成自动标记完成。

| 批次 | 具体交付 | 前置与验收重点 |
|---|---|---|
| B1 分支导航 | 同级回答切换、分支浏览、当前位置恢复 | 直接用当前消息树；运行分支不可被查看操作改写；工具历史不重放 |
| B2 加密备份 | 数据范围预览、口令加密包、认证后恢复、关联重映射 | 先定备份格式/KDF/AEAD 依赖；快照前停止活动任务；错误口令/损坏/空间不足/中断不破坏原库 |
| B3 原生文档上传 | 按协议上传、文件 ID 缓存、过期/清理与进度取消 | 先选一个真实支持文件输入的协议样本；本地抽取保持显式选择；跨端点不复用 ID |
| B4 凭据与成本 | 多 Key 的显式选择规则、按任务选模型、价格与用量汇总 | 只安全存储凭据；真实请求逐次计数；不因切 Key 重做工具；未知费用不伪装精确 |
| B5 通知感知 | 按 App 监听、观察回填、RemoteInput 确认回复 | 真机授权/撤权、过期通知和取消验收；既有截图/前台窗口能力不重建 |

MCP OAuth、resources/prompts、旧 SSE 与网络 Skill 导入分别以实际样本立项，验收范围见扩展设计 §12.1；不混入 E1 的连接成功承诺。

后续 Root、更多子代理并发、Code Mode、定时事件、模板/角色卡与远程访问，按 [扩展设计 §12](./agent_extensions_design.md#extensions-later) 的进入条件立项，暂不预建框架。
