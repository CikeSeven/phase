# 项目模式与共享工作区

项目模式按项目组织会话和文件，复用现有聊天、工具及 Ubuntu 运行链路。

## 界面与导航

- 侧栏“新会话”上方提供聊天／项目标签。切换仅改变侧栏列表、搜索和创建入口，不切换主页面或停止运行。
- 聊天列表只展示普通会话；项目列表按创建时间倒序展示。两种模式分别保留搜索和滚动位置，模式在当前应用会话内保留。
- 项目只填写名称，去除首尾空白后为 1–100 个字符，允许同名。创建成功后进入项目页面，显示名称、创建时间、文件入口及项目会话列表。
- 项目会话保留置顶、重命名、复制、导出、执行记录和删除菜单。空白会话显示“让我们在「项目名」中构建什么？”。
- 项目会话返回所属项目；退出项目页面恢复此前聊天的选择与草稿。侧栏显式选择普通会话时进入普通聊天。

## 数据与目录

- schema 15 新增项目记录和工作区类型，会话以 `projectId` 标识归属。项目 ID 同时作为工作区 ID，目录使用 ID，名称仅用于展示。
- 普通会话首次发送时创建 `/sessions/<conversationId>`；项目创建时立即创建 `/projects/<projectId>`，项目空白会话仍在首次发送时落库。
- 两类目录都位于固定 Ubuntu rootfs 内。文件工具相对路径、shell 默认 cwd、文件页、附件导入和 Skill 副本使用同一工作区快照。
- Ubuntu 尚未安装时仍可建立项目目录并使用文件工具。目录存在不代表环境可执行，安装不会自动触发。
- 环境安装与卸载保留 `sessions`、`projects`、`services`；镜像不能覆盖这些目录。目录归属不构成额外的文件系统访问隔离。

## 项目资料生命周期

- 项目会话上传的附件、抽取文本和工具产物登记项目归属，继续使用应用私有附件存储；工作区文件及副本来源由项目工作区持有。
- 删除项目会话先停止并等待该会话的模型运行与后台任务结束，再删除历史和运行记录、解除附件的会话关联。项目目录、文件、附件、产物及索引全部保留。
- 同项目的其他会话可通过文件工具读取共享目录和项目资料；文件页提供“目录”和“资料”两种视图，支持预览与导出。
- 复制项目会话仍属于同一项目，复制消息与运行历史，复用目录和资料引用。普通会话仍复制独立工作区与附件，删除时清理其独立文件。
- 会话导出仅包含该会话关联或实际引用的资料，不将其他项目会话的资料全部带入导出。

## 并发与升级

- 同一项目的不同会话允许同时运行，共享目录的修改立即可见。项目工作区以引用计数保留运行租约，停止和删除操作按会话归属处理。
- 同一路径写入沿用现有文件操作语义，编辑继续核对原文摘要。环境安装、卸载和目录生命周期操作保持排他。
- 覆盖安装支持既有 schema 10–14 升级至 15，保留旧业务记录和文件；旧工作区及缺少类型字段的运行快照默认属于普通会话。迁移失败回滚，不清理设备数据。
- 首版提供创建和浏览项目、管理项目会话；项目重命名、删除、普通会话迁入及项目专属模型配置留待后续。

代码检查、构建安装与交互验收分别记录；不以生成代码或构建成功替代行为验收。
